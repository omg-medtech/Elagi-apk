# تطبيق عِلاجي (APK)

التطبيق يفتح موقعك https://omg-medtech.github.io/Elagi-app/ داخل تطبيق أندرويد، وفيه خدمة أصلية تُشغّل جرس التنبيه ثم تنطق الجملة بصوت عالٍ حتى والتطبيق مغلق.

## بناء ملف APK (مرة واحدة، من الهاتف أو الكمبيوتر)
1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `Elagi-android`) وارفع إليه كل محتويات هذا المجلد كما هي (بما فيها مجلد `.github`).
2. افتح تبويب **Actions** في المستودع ← **Build APK** ← **Run workflow**.
3. بعد دقائق افتح التشغيل المكتمل ← في الأسفل **Artifacts** ← حمّل **Elagi-apk** وفك الضغط، ستجد `app-debug.apk`.
4. ثبّته على هاتفك (اسمح بالتثبيت من مصدر غير معروف).

## قبل أول استخدام
- ارفع `Index.html` و`sw.js` الجديدين إلى موقع GitHub Pages (التطبيق يحمّل الموقع من هناك، فأي تحديث للموقع يصل للتطبيق دون إعادة بناء).
- عند أول فتح اسمح بالإشعارات والموقع والكاميرا.
- من إعدادات الهاتف ← التطبيقات ← عِلاجي ← البطارية: اختر «بدون قيود»، وفعّل «التنبيهات والتذكيرات» إن طُلب.

## ملاحظات
- التنبيه المجدول يُرسَل من التطبيق للهاتف كل 15 ثانية أثناء فتحه، لذا افتح التطبيق مرة بعد أي تعديل في الأدوية.
- النطق العربي يحتاج أن يكون في الهاتف صوت عربي (إعدادات ← اللغة ← تحويل النص إلى كلام ← Google ← العربية).
